# Beaver Fever

A short 3D game made for the Wavedash Spring Jam. You play a beaver: chop trees for wood, build your dam, and stay out of sight of the wolf and the huntsman.

## Play it

**▶ Play in the browser:** _<[play here!](https://wavedash.com/games/beaver-fever)>_

## How to play

- Chop trees to collect wood.
- Use the wood to build the dam.
- The wolf hunts by sight — your danger meter rises when it notices you. Hide in cover to lose it.
- Watch out for the huntsman too.

### Controls

| Action | Key |
| --- | --- |
| Move | W A S D |
| Sprint | Shift |
| Interact / chop / build | E |
| Eat | F |
| Pause | Esc |

## Running locally

1. Install [Godot 4.6](https://godotengine.org/download).
2. Open `wavedash-spring-jam-26/project.godot` in the Godot editor.
3. Press Play (F5).
